# Инструкция по развертыванию GitHub Pages

## Обзор

Этот репозиторий настроен для автоматического развертывания на GitHub Pages по адресу:
**https://iwasinminedream.github.io/moddota.github.io/**

## Автоматическое развертывание

Развертывание происходит автоматически при каждом push в ветку `source` через GitHub Actions.

### Рабочий процесс развертывания

Файл `.github/workflows/deploy.yml` выполняет следующие шаги:

1. Устанавливает Node.js 22
2. Устанавливает зависимости (`npm ci`)
3. Собирает основной сайт (`npm run build`)
4. Собирает API документацию
5. Загружает артефакт для GitHub Pages
6. Разворачивает на GitHub Pages

## Настройка GitHub Pages (одноразовая настройка)

Чтобы включить GitHub Pages для этого репозитория, выполните следующие шаги:

### 1. Включение GitHub Pages

1. Перейдите в **Settings** (Настройки) репозитория
2. В боковом меню выберите **Pages**
3. В разделе **Source** (Источник):
   - Выберите **GitHub Actions** в качестве источника развертывания
4. Сохраните изменения

### 2. Проверка прав доступа

Убедитесь, что у GitHub Actions есть необходимые разрешения:

1. Перейдите в **Settings** → **Actions** → **General**
2. В разделе **Workflow permissions** выберите:
   - "Read and write permissions"
3. Сохраните изменения

## Процесс развертывания

После слияния этого PR в ветку `source`:

1. GitHub Actions автоматически запустит workflow развертывания
2. Сайт будет собран и опубликован на GitHub Pages
3. Сайт станет доступен по адресу: https://iwasinminedream.github.io/moddota.github.io/

## Локальная разработка

Для локальной разработки и тестирования:


## Проверка статуса развертывания

Чтобы проверить статус развертывания:

1. Перейдите на вкладку **Actions** в репозитории
2. Выберите workflow "Deploy"
3. Посмотрите последний запуск для статуса

## Устранение неполадок

### Сайт не обновляется

- Проверьте, что изменения были отправлены в ветку `source`
- Проверьте статус workflow в разделе Actions
- Убедитесь, что GitHub Pages включен в настройках репозитория

### Ошибки сборки

- Проверьте логи в GitHub Actions
- Запустите `npm run build` локально для диагностики
- Проверьте, что все зависимости установлены

### Проблемы с путями/ссылками

- Убедитесь, что `baseUrl` в `docusaurus.config.js` соответствует имени репозитория
- Все внутренние ссылки должны использовать относительные пути или включать baseUrl
